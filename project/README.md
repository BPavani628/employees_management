# Employee Management System (EMS)

A Django-based Employee Management System that allows an administrator to manage employee records through a clean web interface with full CRUD functionality.

## Key Features
- **Admin Authentication:** Secure login and session logout.
- **Dashboard:** Real-time statistics including total employee count, payroll summary, and average salary.
- **Employee Directory:** View all records in a responsive table.
- **CRUD Operations:** Add new employees, view full details, update existing records, and delete with a confirmation modal/page.
- **Search:** Filter employees dynamically by Employee ID or Name.
- **Data Validation:** Enforces unique Employee IDs, valid email format, structured phone numbers, and positive salary constraints.

## Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML5, Bootstrap 5, Bootstrap Icons
- **Database:** SQLite3 (Django ORM)
